V8.3 — CONTROLOS DO CONVITE

Alteração solicitada:
Menu / Música / Acesso administrativo.

- O Menu é o único controlo com moldura/caixa quadrada.
- Música fica apenas com o ícone; não tem círculo, fundo ou moldura.
- Acesso administrativo fica apenas com o ícone; não tem círculo, fundo ou moldura.
- O acesso administrativo aparece apenas enquanto o Welcome/primeira página está aberto.
- No estado Welcome, os três controlos ficam alinhados no topo, na ordem Menu → Música → Acesso.
- Depois de abrir o convite, o acesso administrativo desaparece.
- A mesma regra vale para mobile e desktop.
- A navegação e os links existentes permanecem funcionais.
