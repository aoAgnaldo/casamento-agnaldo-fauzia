CHECK-IN — Agnaldo & Fáuzia

1. No Supabase, abra o SQL Editor e execute checkin.sql.
2. Substitua os ficheiros do site pela versão deste ZIP no GitHub Pages.
3. Entre em admin.html com a conta de administrador.
4. No dia do casamento, use a área Check-in para:
   - pesquisar manualmente pelo código;
   - ler o QR Code com a câmara do telemóvel;
   - confirmar a entrada;
   - anular uma entrada se houver engano.

O QR Code dos convites V2.5 já contém o parâmetro ?convite=CODIGO, por isso pode ser lido directamente pelo painel.
