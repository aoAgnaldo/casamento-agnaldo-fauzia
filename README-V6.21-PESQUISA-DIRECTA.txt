V6.21 — Pesquisa directa de convidados

Novidade:
- A recepção pode pesquisar por nome completo ou código do convite.
- Código exacto abre directamente o convidado.
- Nome exacto abre directamente o convidado.
- Pesquisa parcial mostra uma lista de resultados seleccionáveis.
- Cada resultado mostra nome, código, número de pessoas, mesa e estado de entrada.
- Ao seleccionar, o cartão normal mostra a mesa e permite confirmar a entrada.
- Compatível com QR Code e fluxo existente.
- Sem SQL novo.
